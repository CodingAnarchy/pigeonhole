### Changed
- `Options::adaptive_shard_threads(true)` (off by default) resizes the shard threads more steadily (#1015). It adds threads when shards wait on each other's turns, or when a thread is almost always busy. It removes them only when the work is light and threads keep parking, and it never goes below two. It no longer adds threads for long background turns alone, or undoes a shrink on a short dip in throughput. On the reference machine, a wide-row write load with it on now keeps put p99 at 67–142 µs, against 391–623 µs with one thread per shard, while transfer, ycsb-a and ycsb-f stay level.
