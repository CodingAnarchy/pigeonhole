### Changed
- **`CpuProfile::Server` has a shard thread that handled a commit poll 1 ms for the next one before it sleeps, instead of 200 µs** (D198 amended, ICR 0081 amended, #760). `CpuProfile::Embedded`, the default, is unchanged. On the reference machine, sparse-wide's `Buffered` put p99 fell from 49.8 to 27.4 µs and p99.9 from 1.47 to 0.96 ms, and at default durability its put p99 fell from 390 to 123 µs; ycsb-a, ycsb-f, transfer and counters were level. The cost is CPU under a moderate steady load: ycsb-a paced to 20K ops/s used 2.9 cores against 0.65, and sparse-wide `Buffered` ran 6% fewer ops/s on 1.6 more cores. That is why only `Server`, for a database with the machine to itself, takes it. An idle database still never polls.
