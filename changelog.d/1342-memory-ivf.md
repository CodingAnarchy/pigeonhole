### Added
- `pigeonhole-memory`: IVF recall for large namespaces (D311 T8, #1342). A store created with `StoreOptions::ivf(IvfOptions)` keeps a `pigeonhole-vector` index of its embeddings, written in each memory's own transaction. Recall searches it for a namespace of at least `IvfOptions::min_namespace_len` memories with an embedding (10,000 by default), and searches smaller ones exactly. `Recall::exact` and `Recall::nprobe` adjust a recall, `RecallStats::ivf_namespaces` and `ivf_fallbacks` say which path ran, and `verify` checks the index (`StoreStats::ivf_mismatched`, `ivf_counter_drift`).
- `pigeonhole-vector`: `Search::id_prefix`'s documentation gives its cost, a seek per probed list (#1342).
