### Added
- `Options::caller_runs`, an opt-in that is off by default (D321, ICR 0128). With it on, a thread waiting on its own single-shard `Buffered` or `None` commit runs the shard's work itself when no other thread is running that shard, instead of waiting for the shard's thread to be scheduled. It's for buffered writers of large values or wide rows that care about put tail latency: on a contended 16-thread load, sparse-wide put p99.9 fell from 473 to 94 µs. It costs hot, short commits throughput and p99 (counters −18%, YCSB A −10%), so it is not a default. See the guide's performance page.
