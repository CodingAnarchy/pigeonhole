### Changed
- `phdb`: the binary (CLI, `phdb serve`, `phdb mcp`) uses jemalloc as its memory allocator on every platform but Windows, through `pigeonhole-cli`'s new default `jemalloc` feature (D322). On a 16-core machine, against glibc's malloc, jemalloc measured +9% to +21% throughput on read-heavy work at 16–32 threads, for 0–20% more peak memory. Building it needs a C compiler and `make`; `--no-default-features --features embed` leaves it out. The library crates still choose no allocator: the guide's new "Allocator" section (performance.md) has the numbers and how an application sets one (#1558).
