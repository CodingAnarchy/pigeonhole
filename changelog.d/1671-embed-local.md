### Added
- **`--embed-local` for `phdb mcp` and `phdb serve --memory`** (the `embed-local` feature, off by default, #1345, D318, ICR 0119): memory text is embedded in the process, on the CPU, with `pigeonhole-embed`'s `BAAI/bge-small-en-v1.5`, with no embedding service. Memories are embedded as passages and recall text as queries, and a new store is pinned to `BAAI/bge-small-en-v1.5@5c38ec7c`. `--embed-model-dir` loads model files from a directory, and `--embed-offline` never downloads. `phdb serve` keeps the embedder's threads off the shards' CPUs and, when the shards are pinned and `CANDLE_CPU_MASK` is unset, prints the `CANDLE_CPU_MASK`/`CANDLE_NUM_THREADS` values to start with.
