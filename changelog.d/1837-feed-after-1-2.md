### Fixed
- **After running 1.2, a 1.1.x open that doesn't name the change feed (`phdb`, a tool) could turn it off** (#1837). It kept the feed on only if 1.2's last sidecar entries were plain roots: after a 1.2 schema change, or a 1.2 crash inside a root commit, it recorded the feed off, and every token and replica expired. It now steps over 1.2's catalog and intent entries, and resolves a 1.2 crash's intent as 1.2 does, so returning to 1.2 keeps the feed too. Tokens taken before a 1.2 schema change still expire under 1.1.x, which can't read the change: they end with `FeedExpired`, never an error, and resume again once back on 1.2.
