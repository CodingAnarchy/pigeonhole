### Fixed
- Reads: a row read with a qualifier filter that keeps nothing in the row now ends at the row. So does a walk of one row's cells (`RowRead::cells`). Before, the read skipped past such a row by seeking to the next one, and then the one after, through the rest of each file it read. For example, a text search with an `id_prefix` that no document has (an empty tenant) cost more than the same search without the prefix: on the text bench's 100,000-document index on a Mac, a rare term took 1.1 ms where it now takes 5 µs, and a fuzzy term took 47 ms where it now takes 0.3 ms (#1924).
