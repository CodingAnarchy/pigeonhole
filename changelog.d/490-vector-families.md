### Added
- Vector families (D303, ICR 0098): `Family::vector(VectorSpec::new(dim, Element, Metric)?)` fixes every value's element type (`F32`, `I8` or `Bit`), dimension (1 to 4096) and distance metric (L2, inner product, cosine or Hamming). Write vectors with `put_vector_f32`, `put_vector_i8` and `put_vector_bits` (and `_at` forms) on a mutation, a write batch or a transaction; a vector of another shape, a non-finite component or an all-zero cosine vector is refused when the write is built. Read them as `Value::Vector` or `CellRef::as_vector`, and score them with `VectorSpec::distance_f32`, `distance_i8` or `distance_bits`, exactly as the engine ranks them. Creating the first vector family marks the file so that pigeonhole 1.0.x refuses it.
