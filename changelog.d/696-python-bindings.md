### Added
- Python bindings (`crates/python`, PyPI name `pigeonhole-db`, `import pigeonhole`; D307, ICR 0102), over PyO3 with the GIL released during engine calls (#696). They cover opening as the writer or a reader process, tables and families (counters and every aggregate kind), gets, row reads and chunked scan iterators, row mutations and conditional commits, write batches, snapshots and transactions as context managers, `transact` with retries, and an exception per `ErrorCode`. There are typed stubs checked by stubtest, and abi3 wheels (CPython 3.11+) for Linux, macOS and Windows are built in CI. Not yet published to PyPI.
