### Fixed
- `compact()` now purges a last level of several SSTs too, when one of them may hold purgeable entries: versions beyond `max_versions`, expired cells, tombstones no snapshot needs. A run written while a snapshot held its purge back used to keep every version and marker through every later `compact()` (#820). An SST written by a compaction that nothing held back now records that in its properties (D268), so a table with several columns per row in a `max_versions` family is not rewritten again by each `compact()` call; SSTs written before this change are rewritten once.
