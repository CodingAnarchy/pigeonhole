### Fixed
- A database handle used in a process forked from the one that opened it no longer runs the parent's engine (#901). Before, closing or dropping the child's copy ran a full close on the parent's database (flushes, log writes, a root commit) and could hang on threads that exist only in the parent; any other operation could hang or read shared memory the parent was reusing. Now every operation on it fails with `Unsupported` ("opened in another process (fork); open it again here") at once, and close and drop do nothing. Open the database again in the child. Only `fork(3)` is detected (`_Fork`, `vfork` and a raw `clone` skip fork handlers).
