### Changed
- Reader processes read overwritten rows as fast as the writer process (#930, #397, D277). The writer's index of where a column's superseded memtable versions end (D194) lived in its own memory, so reader processes stepped over every superseded version: a reader read the 16 hottest rows of ycsb-a at a third of the writer's speed (15.1 against 4.7 µs per read, row cache off). The writer now stores that offset in each memtable entry, in shared memory, and readers jump by it. The shared-memory layout version is now 4: **upgrade reader processes together with the writer.** Readers from earlier releases can't attach to this writer's shared memory, nor the reverse (`ShmVersionMismatch`); the new writer rebuilds it once every older process has closed. Each memtable entry takes 4 more bytes of arena, and the writer no longer keeps the separate index (an eighth of its arenas' size in process memory).
