# pigeonhole-cli

phdb: the command-line tool for Pigeonhole databases, planned for Phase 4.

**This crate is a placeholder.** The `phdb` binary does nothing yet: it prints "not yet implemented" and exits with status 2. The planned commands (`shell`, `dump`, `compact`, `check`, `backup`) do not exist.

This is an internal crate of [Pigeonhole](https://github.com/CodingAnarchy/pigeonhole). Most users want the [`pigeonhole`](https://crates.io/crates/pigeonhole) crate.
