# pigeonhole-io

Vfs abstraction for Pigeonhole: files, aligned buffers, completions, direct I/O, a pread pool, an io_uring backend (Linux) and a fault-injecting simulated backend.

This is an internal crate of [Pigeonhole](https://github.com/CodingAnarchy/pigeonhole). Most users want the [`pigeonhole`](https://crates.io/crates/pigeonhole) crate.
