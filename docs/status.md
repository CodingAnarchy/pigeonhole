## What's in 0.3.0
The full list, with an upgrade guide, is the [changelog](../CHANGELOG.md#030---2026-10-20).
- **Commits:**
  - a commit is visible once applied, before its fsync, and returns once durable at its level ([D227](design/decisions/phase-3.md#d227), amends D19); durable snapshots and `backup_durable` keep the old view (ICR 0037; shared-memory layout 2);
  - concurrent durable commits share group syncs ([D207](design/decisions/phase-3.md#d207), [D221](design/decisions/phase-3.md#d221));
  - no engine-wide writes on the commit path ([D236](design/decisions/phase-3.md#d236)), and an application-owned `run_once` returns once it settles an awaited commit ([D237](design/decisions/phase-3.md#d237));
  - a client waits 50 µs before parking ([D253](design/decisions/phase-3.md#d253)) and a shard 200 µs ([D198](design/decisions/phase-3.md#d198), amended); a conditional commit waits for the next group only when its group wrote the cell it reads ([D260](design/decisions/phase-3.md#d260)); and engine-owned flush and compaction run on threads of their own ([D252](design/decisions/phase-3.md#d252));
  - WAL rollover, spare preparation, file growth and WAL pin passes off the commit path ([D200](design/decisions/phase-3.md#d200), [D206](design/decisions/phase-3.md#d206)); fewer copies and allocations per commit (#320).
- **Cross-shard commits:** a commit's timestamp stays in seqno order with its participants' writes ([D244](design/decisions/phase-3.md#d244), #653; also in 0.2.3), checked exactly by seqno so contention costs few retries ([D245](design/decisions/phase-3.md#d245), #637, #655); an overlap with an undecided share is retried, not a `Conflict` ([D249](design/decisions/phase-3.md#d249)); a flush reports its settled shares in one message per shard ([D254](design/decisions/phase-3.md#d254)), rescans its shares only when their slots flushed (#761), and pops its WAL checkpoint in bounded batches (#764, #727).
- **Async front door:** an async form of every data operation, on by default (#42, [D196](design/decisions/phase-3.md#d196)).
- **I/O:** io_uring by default on Linux ([D218](design/decisions/phase-3.md#d218)), direct I/O (#403), application-owned mode with no engine threads, `Shard::wait` and `Shard::waker` ([D202](design/decisions/phase-3.md#d202), ICR 0035).
- **Reads:** one-I/O cold gets (ICR 0039, [D215](design/decisions/phase-3.md#d215)), stale-tail and SST column skips ([D194](design/decisions/phase-3.md#d194), [D199](design/decisions/phase-3.md#d199), ICR 0041), the row cache on by default ([D201](design/decisions/phase-3.md#d201), [D216](design/decisions/phase-3.md#d216)), scan readahead ([D222](design/decisions/phase-3.md#d222)), block-cache hits that scale across threads (#18).
- **Placement and threads:** one shard per physical core ([D220](design/decisions/phase-3.md#d220)), threads pinned by default ([D235](design/decisions/phase-3.md#d235)), balancer packing, damping and closed-loop rules ([D214](design/decisions/phase-3.md#d214), [D217](design/decisions/phase-3.md#d217), [D224](design/decisions/phase-3.md#d224)), packing sized by the commits in flight, cross-shard ones at every participant ([D257](design/decisions/phase-3.md#d257), [D262](design/decisions/phase-3.md#d262)), that counts group syncs, stalls and pool work as busy and grows past a saturated shard ([D248](design/decisions/phase-3.md#d248), [D251](design/decisions/phase-3.md#d251), [D255](design/decisions/phase-3.md#d255), [D256](design/decisions/phase-3.md#d256)), and a bulk-loaded table that splits while compacting ([D241](design/decisions/phase-3.md#d241)).
- **Stalls and failures:** the L0 stall at 2× `l0_trigger` ([D234](design/decisions/phase-3.md#d234)), a per-write stall timeout ([D240](design/decisions/phase-3.md#d240)), cross-shard retries until that timeout ([D241](design/decisions/phase-3.md#d241)), room waits that freeze the largest memtables ([D124](design/decisions/phase-1.md#d124), #642), `ErrorCode::OutcomeUnknown` with `Closed` meaning not committed (ICR 0038), the health check with its [recovery guide](guide/recovery.md) (ICR 0040), and `engine_metrics()` as documented public API (ICR 0044).
- **Gate method:** group commit judged under full load ([D213](design/decisions/phase-3.md#d213), [D219](design/decisions/phase-3.md#d219), [D226](design/decisions/phase-3.md#d226)); scaling and placement judged apart ([D231](design/decisions/phase-3.md#d231)), up to one chiplet ([D238](design/decisions/phase-3.md#d238)); the bench settles, warms up until placement settles, and judges runs of 10 s or more with absolute latency floors ([D233](design/decisions/phase-3.md#d233), [D242](design/decisions/phase-3.md#d242), [D243](design/decisions/phase-3.md#d243), [D259](design/decisions/phase-3.md#d259)); contended p99 reported per operation type ([D261](design/decisions/phase-3.md#d261)); the memtable target's size and its acceptance ([D230](design/decisions/phase-3.md#d230), [D239](design/decisions/phase-3.md#d239)); contended cross-shard commits and every public operation under contention on the default options ([D246](design/decisions/phase-3.md#d246), [D247](design/decisions/phase-3.md#d247)); a trimmed file system before every step ([D258](design/decisions/phase-3.md#d258)).
- **Considered and not adopted:** [D228](design/decisions/phase-3.md#d228), [D232](design/decisions/phase-3.md#d232).
- **Releases from `release/0.2.x`, also in 0.3.0:** [0.2.1](https://github.com/CodingAnarchy/pigeonhole/releases/tag/v0.2.1) (D209) and [0.2.2](https://github.com/CodingAnarchy/pigeonhole/releases/tag/v0.2.2) (the cross-shard close fixes, [D225](design/decisions/phase-3.md#d225), #591, #597) and [0.2.3](https://github.com/CodingAnarchy/pigeonhole/releases/tag/v0.2.3) (the cross-shard timestamp order, D244 and D245 without the room refusal).
